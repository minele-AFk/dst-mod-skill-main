# 发布前自检清单

## 文件、环境与接口

- [ ] 记录真实源码、运行副本、版本和本轮改动；用户原有文件、存档与无关 Mod 得到保留。
- [ ] PrefabFiles 能加载对应脚本，返回的各个 Prefab 名和依赖正确；文件名与注册名按用途核对。
- [ ] Lua 环境、require、配置读取与世界可用时机明确；不要求统一 env 代理，也不按文本出现 GLOBAL、pcall/xpcall 等一概判错。
- [ ] 主组件、Replica、原生绑定与项目 helper 分开核对；声明匹配、未覆盖调用和真实运行结果分别记录，见 [工具台账](../tools/README.md#api-声明检查)。
- [ ] netvar 创建顺序、权威写入、dirty 名称、首次读取、房主显示与专服分支符合当前合同。
- [ ] 事件 data 与 source 对照生产端；任务、外部监听、modifier、输入句柄与临时 FX 有清理责任。
- [ ] 组件 OnSave 返回数据，实体 OnSave 填写传入数据；加载不依赖组件固定顺序，旧档缺字段与实体引用恢复已处理。
- [ ] 配置 nil 兜底保留 false/0；台词、显示名和翻译按实际支持角色与当前 STRINGS 结构检查。

## 资源与数值

- [ ] bank、build、symbol、动画名分别取自实际资源；换符号包与播放动画包的结构按用途检查，不强制所有 ZIP 三件齐全。
- [ ] 图集、贴图、sampler、Element 与 Lua 注册引用可对应；输出由确认过的工具生成，源工程和原资产仍可回退。
- [ ] 动画帧数、纹理页、画布与锚点按产物和目标效果验证，不套用 60/149 帧或正方形图集等通用限制。
- [ ] 贴图原尺寸、透明边缘、动画层级/pivot 与实际 HUD 效果有相应检查；本地预览与游戏渲染分别记录。
- [ ] 音频 bank/event、触发端和空间效果已按实际目标试听；专服无错误不能代替听感。
- [ ] 数值有明确来源与设计依据；Prefab、配方、调味/升级、说明与配置的差异符合设计。
- [ ] 料理选择、制作扣费/交付、升级与维修使用实际当前合同，未用单一常量或成功生成日志代替完整结算。

## 功能与回归范围

- [ ] 本次影响的正常、拒绝、取消、移除及异常路径已检查，报告实际环境、输入与结果。
- [ ] 影响联网时覆盖房主和独立远端客户端，必要时覆盖专服/洞穴；纯客户端功能不以专服 PASS 代验。
- [ ] 影响保存时覆盖保存重启、重连和旧档恢复；离线追赶、死亡与复活按已确认设计验收。
- [ ] 隔离 runner 若使用，则核对本轮 ID、实际加载路径、完整断言后的 TEST.Done、观察窗及异步错误；未使用则不填写通过。
- [ ] 结束和清理只针对本轮创建且可确认归属的进程/副本；保留所需证据，不以固定端口判断所有权。
- [ ] 未测项写明范围、原因及需要的下一步；状态以 [本机回传模板](local-validation.md) 记录。

## 打包与发布

- [ ] modinfo 的内容、兼容字段、客户端要求、图标与配置符合实际代码形态和当前工具要求。
- [ ] 包中只有已确认的运行文件与必要资源；不带私人存档、凭证、调试缓存、测试快照或未授权第三方资料。
- [ ] 发布源是可追踪的当前副本；派生产物从源文件重新生成，并检查 Manifest、路径与哈希，未手改生成包掩盖差异。
- [ ] 多副本同步只到本轮授权目标，比较后核对内容；Workshop 等外部目标和提交、推送、发布分别有明确授权。
- [ ] 版本处理和更新说明遵从用户本轮要求；明确要求不改版本时保持版本文件。
- [ ] 实际上传目标、发布内容与完成状态有记录；准备好文件不等于已经发布。

源码与原理见 [工程测试与交付](../engineering/dst-mod-engineering/testing-release.md) 和 [旧规则纠错](../pitfalls/old-rule-corrections.md)。
