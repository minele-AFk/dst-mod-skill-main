# Layout 与 Retrofit

## Layout

静态布局描述相对坐标、地皮和对象。接入前确认：

- 原点与边界
- 旋转和镜像
- 地形限制
- 对象 Prefab 与数量
- 随机替换
- 受保护资源
- 与 Room 或 Task 的连接

## Retrofit 幂等流程

1. 读取保存的 retrofit_version。
2. 如果版本已完成则返回。
3. 检查目标实体或完成标记是否已存在。
4. 在有限次数内搜索合法区域。
5. 先创建本次实体列表。
6. 全部成功后建立引用并写完成版本。
7. 部分失败时移除本次创建或保存可恢复的阶段。
8. 无合法位置时记录状态，不做无限全图搜索。

## 旧世界风险

旧世界可能有玩家建筑、改变后的地形、已清空资源和其他模组布局。搜索应远离关键基地并避免自动删除未知实体。对无法安全补入的内容，允许跳过并向用户说明。
