## 选图与制作卡

先查看图片，记录画布、alpha 边界和用途。原文件透明区在查看器中可能显示黑底；先检查 alpha，不把黑色显示背景写进提示。小图只支持判断可见线面关系，不能断言作者使用的笔刷、矢量软件或绘制方法。

参考不是越多越好：一张主画风图，按需增加结构图或局部材质图。两张画风差异明显的图，先按目标选择；不要写“融合所有参考”。输入图片顺序与提示中的 A/B/C 必须一致，实际传图而不只写路径。

| 参考角色 | 可以迁移 | 不自动迁移 |
|---|---|---|
| A：原图 / 已确认版本 | 用户要求保留的轮廓、比例、部件、配色与视角 | 原图模糊、坏线、被用户否定的画法 |
| B：主画风 | 内外线相对粗细、收笔、明暗边界、材质概括与细节层级 | 物体种类、配饰、花纹、姿势、颜色，除非用户指定 |
| C：可选局部参考 | 指定的材质或结构关系，例如玉石表面、环绕遮挡 | 整件风格、比例和所有装饰 |

每次生成前写简短制作卡，已有明确要求直接填，不让用户重复决策：

```text
资产职责 / 目标尺寸：
保留优化 或 重新设计：
结构：主体、连接方式、视角；必要时列刃/柄/饰件相对比例。
不可变：用户已认可的形状、配色、数量和重要特征。
主画风图：文件 + 可见的 3–5 项特征（外线/内线、明暗、材质、疏密）。
细节层级：远看识别特征；中等尺寸结构；放大才见的装饰。
本轮只解决：最影响效果的 1–3 项。
交付与验收：原始透明母图；所需尺寸；与哪张参考并排看。
```

物品、人物、建筑各自选同职责基准。人物还需头身比、五官、发束、衣褶、正侧背方向和部件尺度；武器例图只能补充线条或材质，不能决定人物比例或脸部画法。缺少人物主参考且会影响设计时，应询问，不套武器模板。

## 提示模板

提示顺序：任务与图片职责 → 结构/保留项 → 参考中最关键的画法 → 本轮变化 → 输出。优先写可检查的形状和关系，删除泛泛的“杰作、8K、极致细节”和重复否定词。语言服从表达清晰度，不因使用英文而假定更准确。以下是组装模板，不把空字段或所有可选规则原样发给工具。

### 保留造型、只优化画风

```text
将 A 重绘为透明背景的 [职责] 贴图。A 只提供设计，B 是主画风参考。
保留 A 的 [轮廓、关键部件及连接、相对比例、视角、配色关系]。
采用 B 的 [具体线条特征]、[明暗边界与高光画法] 和 [装饰疏密]。
优化 [本轮 1–3 项]。主识别特征 [X] 在 [目标尺寸] 下仍清楚；
细小装饰服从主体，不新增饰件。只输出完整单件，RGBA 透明底，保留边缘余量。
```

例如以细线蓝白刃作画风参考时，可写“外轮廓深紫而清楚，内部线更轻；窄亮刃与蓝紫暗面形成厚薄，亮面留净”。只有参考确实支持时才写；不能顺手要求新物体也变蓝白、加尖刺。

### 重新设计

```text
制作 [已选方向] 的 [物品职责] 透明贴图。B 只提供画法。
新结构：[主体轮廓、功能部件、相互位置与比例、允许的装饰范围]。
采用 B 的 [3–5 项具体画法]。焦点位于 [部位]，其余区域保持 [疏密关系]。
必须保留的题材特征：[用户要求]。避免本轮已发生的错误：[少量具体项]。
单件完整呈现，RGBA 透明底，适用于 [尺寸/用途]。
```

用户已否定的成品不能继续作为默认主风格图。需要说明错误时将其标为反例，不与目标混合；新设计方向未定则先提供简短选项。

### 局部修改

```text
编辑 A。本轮仅修改 [区域与可见变化]。
保持 [已确认造型、比例、视角、配色及其他部件]。
[必要时：B 仅示范该区域的线条/材质]。
```

精确修改不要再附整套新设计形容词。若多轮编辑导致线条或结构漂移，回到最近用户认可的母图并合并必要修改，不不断沿用失败版本。

## 反馈诊断

| 反馈 | 先分辨 | 本轮处理 |
|---|---|---|
| 画风不对 | 线重、边界软硬、体积表现还是整体比例不同 | 重选主参考/删冲突风格词，针对不同之处改；不默认加细节 |
| 不够精美 | 坏线、连接草率、焦点弱、疏密失衡还是细节缺失 | 修明确缺陷；细节不足才补必要装饰，不追加全图划痕 |
| 不像手绘 | 等粗几何边、喷枪体积或机械重复 | 学参考的收笔、线重与形体概括；不要靠噪点和抖动制造手绘 |
| 剑身/手杖太长 | 结构比例还是画布占比 | 结构问题改刃柄/头身比例；展示问题调留白；两者分开 |
| 龙纹像贴上去 | 缺少前后遮挡、绕柱弧度或宽度变化 | 写清前侧可见、侧边转向、背侧遮挡的连续路径 |
| 龙纹像长了东西 | 浮雕厚度、投影或外轮廓突出 | 贴合表面、浅刻/齐平镶嵌，减少侧壁与投影；不生成独立活龙 |
| 古木太脏 | 材质方向不足还是噪点过多 | 少量沿杖身的弯曲纹理与色差；不靠密裂痕堆旧感 |
| 64 模糊 | 原画即糊、缩放丢线、半透明变淡还是纹样太密 | 对应修母图、细线尺度、alpha 或层级；锐化不能救结构 |

“神话感”“中国风”需落实到用户认可的器形、材质和纹样关系。未查清的历史形制不写成事实；文化专名辅助表达，不把某个英文部件词当作造型错误的必然原因。

## 原尺寸验收与迭代

1. **结构**：原图满意时，不变量是否保住？短杖是否仍被拉成法杖？连接与缠绕前后关系是否成立？
2. **风格**：和主参考并排看线重、亮暗过渡、色块、材质、高光与疏密。仅“64 可认”或“终稿感”不能替代风格相似。
3. **细节**：256 看连接、线条和装饰完整；64 看剪影、主色、焦点与必要结构，允许次级纹样合并成色块，不要求所有微细节逐个可辨。
4. **文件**：透明区、半透明边、浅深底无残色；没有不明孤立像素撑大边界。自动裁切前确认尾穗、刃尖等真实细部没有被当作杂点。
5. **展示**：提供独立 256、64 文件及原尺寸预览。REVIEW 上明确区分原尺寸与放大辅助；客户端可能缩放整张图，应保留可打开的单文件。人物/世界部件另按真实装配尺度核对。

不以滤镜、简单缩放、补锐化声称完成风格重画。发现失败先指出最大差异和本轮处理，再按已有授权进行有界修改；不消耗额度做无关线路测试或盲目连抽。用户确认后才更新正式库；失败稿不能混成“已认可画风”。

## 不生图的流程回归

维护本流程时检查以下输入会产生正确的制作卡与提示；这些检查只验证决策，不代表生成效果通过：

后处理代码变更时，可在本专题目录运行 `python -B tools/test_process_texture.py`：验证半透明线不额外变淡、默认 RGBA 原样保留、显式抠底和原尺寸预览。这些离线测试不调用生图服务。

| 输入 | 应出现 | 不应出现 |
|---|---|---|
| 满意原造型，只要图一的画法 | 锁结构；B 的细线、刃缘明暗 | 强制黑红厚刃、重新设计配饰 |
| 蓝珠参考，要求更精致 | 局部柔和体积、高光与金框层次 | 一律禁渐变、一律要求晶体硬棱 |
| 不满意造型，已选择新方案 | 新结构明确；参考只负责画风 | 把被否定版本继续设为主锚点 |
| 人物重绘，只提供武器例图 | 仅迁移可见线/材质；补人物结构基准 | 武器材质决定脸部、64 图标决定角色尺度 |
| 256 清晰但 64 模糊 | 检查线重、细节层级、alpha 和缩放 | 无条件增加纹样或再次随机生图 |
| 明确要原版 DST 建筑 | 同类原版参考、建筑视角与尺寸 | 自动用新增蓝紫武器样本 |
