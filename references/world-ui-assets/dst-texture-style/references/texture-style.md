## 整体视觉语言

DST 贴图把舞台剪纸般的清楚轮廓、松动的墨线、夸张结构和受控的脏旧材质组合在一起。画面不是扁平图标，也不是写实插画：形体高度概括，但接缝、木纹、毛束和阴影线提供触感。

保持以下层次：

1. 远看先识别轮廓和功能。
2. 中等尺寸识别主要色块、脸、握点和活动结构。
3. 放大后才看到刻痕、排线、破边和次级高光。

如果细节在 1x 尺寸结成灰泥，删掉它；如果缩小后只剩均匀黑边和纯色填充，补充结构线与大明暗。

## 轮廓与形体

- 使用轻微不对称、大小不均、边线不完全平行的形体。
- 让重要特征偏大：斧刃、牙齿、眼睛、把手、锁、爪、角和交互部件承担识别。
- 世界物体常用略俯视的三分之四视角，让顶面、正面和侧面同时提供结构。
- 用压扁、拉长、倾斜和错位表达性格与重量，但保持铰链、握点、落脚和受力合理。
- 避免完美圆、完美镜像、CAD 直线和均匀圆角；也避免每处都随机歪斜。
- 让外轮廓有大、中、小节奏：主形体、次级凸起、少量毛刺或缺口。

先只画纯黑剪影并缩到目标尺寸。若同类别物体无法区分，继续调整比例，不靠内部纹理补救。

## 线稿

使用暖黑或近黑墨线，并建立明确线重层级：

- 外轮廓、遮挡交界、深缝和受力处最重。
- 内部结构、材质分区和亮侧边缘较轻。
- 毛发、木刺、运动强调和脏旧感使用短促外伸线或断裂回声线。
- 排线跟随表面方向，密集处形成阴影，稀疏处提示材质。

线条应有手部压力变化和轻微抖动，但端点、接缝与轮廓意图明确。不要使用同宽矢量描边、规律虚线、均匀草稿抖动或所有边缘双描。

抗锯齿边缘可以有半透明像素。不要用纯白底绘制后直接抠图，否则黑线边缘会产生白晕。

## 明度与颜色

先建立 3 到 5 级明度组：

- 近黑：轮廓、孔洞、深缝、投影和材质刻痕。
- 暗中间色：背光面、底面和主要体积阴影。
- 主色：占最大面积，通常比现代 UI 插画更灰、更脏或更偏暖。
- 亮面：少量平面或边缘，用来说明朝向。
- 焦点色：眼睛、宝石、火焰、魔法、食物或可交互部件。

让阴影更像形状明确的色块与排线组合，不做均匀环境光遮蔽。允许局部渐变或柔边服务于 FX、发光和透明材质，但实体表面不要依赖光滑 3D 渐变塑形。

控制彩度分配：大面积材质保持低到中彩度，焦点色可以更纯。避免整件资产同等鲜艳，也避免把所有材质压成单一棕灰。

## 材质词汇

- 木材：沿长轴画不规则纹理，端面使用环纹和裂口；深缝近黑，亮木面保留大色块。
- 金属：用硬折面、缺口、短划痕和少量亮边表达，不用镜面照片反射。
- 石头：使用不均匀块面、裂纹和局部崩边，避免铺满随机噪点。
- 毛发：先画成簇轮廓和大暗面，再加少量顺势毛线；不要逐根均匀绘制。
- 布料：用折线、缝线、补丁和压暗褶皱表达柔软，轮廓仍需清楚。
- 骨、牙和角：用偏暖浅色、根部暗色、裂痕和不等长尖端，避免纯白塑料感。
- 有机物：强调挤压、鼓包、下垂与湿润焦点，保持可读的主体结构。
- 魔法与宝石：允许更高彩度和亮暗反差，但用近黑结构或清楚外形接回 DST 世界。

不要在所有材料上覆盖同一纸纹、颗粒或磨损贴图。材质痕迹必须解释表面方向、使用方式或故事。

## 透明边与画布

- 输出 RGBA PNG，背景完全透明。
- 在透明、浅色和深色背景分别检查边缘，不留白边、灰框或残余底色。
- 保留外伸墨线与抗锯齿所需的少量 padding；不要让裁切框切断黑线。
- 对静态世界物体可紧裁，但 pivot 和 SCML 坐标决定最终画布，不以文件最小化为唯一目标。
- 对换帧部件保持语义 pivot 稳定，允许不同帧尺寸不同，但必须补偿裁切位移。
- 全透明 100x100 文件常用于 swap、snow、frozen 等 symbol 占位。保留被代码或 build 依赖的占位，不把它加入风格统计。

运行 `analyze_textures.py` 比较目标与同类参考。重点观察尺寸、bbox occupancy、visible fraction、partial alpha、暗部比例和主色，不单独用任何指标判定风格。

## 展示实际大小（进游戏看起来多大）

三种「大小」不要混（对照 [assets/vanilla/DISPLAY_SIZE_BOARD.png](../assets/vanilla/DISPLAY_SIZE_BOARD.png)）：

| | 是什么 | 怎么调 |
|--|--------|--------|
| UI 图标感知大小 | 图在 64 格子里的**内容占比** | 调留白 / `content_ratio`（工具约 50–70%，偏满装备可到 85–95%） |
| 世界展示大小 | 地上/建筑/手持看起来多大 | 改 **world/swap symbol 像素尺寸** 后重编 build，或 `AnimState:SetScale` / prefab 缩放 |
| 母版画布（256 等） | 只是画得清不清楚 | **不等于**上面两者；进游戏大小由 symbol/anim 决定 |

原版量级（默认 zoom）：角色约 200px 高量级；工具/武器 world 常见 100–200px；小掉落物 80–150px；建筑件可到 200–300px+；FX 不受实体尺寸约束。

生成/编辑后的标准后处理用 `tools/process_texture.py`（默认保留颜色与 alpha，trim+fit、出 64 图标与 256 画布、可选原尺寸 REVIEW 拼板；纯色背景需显式 `--key-background`，不自动擦除右下角）：

```powershell
python tools/process_texture.py <generated.png> --name my_item --out .tmp/.output/tex --review
python tools/process_texture.py <generated.png> --name my_item --out out --icon-ratio 0.55 --content-ratio 0.80
```

## 动画拆件

按运动和遮挡拆件：

- 关节两侧需要独立旋转或换帧时拆开。
- 前后穿越身体的肢体、武器或门板分离，允许 z_index 动态变化。
- 需要 OverrideSymbol 的帽子、手持物、脸、冻结层或状态覆盖使用稳定 symbol 名。
- 相邻部件在最大动作幅度下仍有足够重叠，不露透明裂缝。
- 被遮挡区域可以简化，但不能在换层或镜像时突然露出缺口。
- 旋转部件在 pivot 周围保留完整结构，不把关节描边裁掉。

完成拆件后用 `[dst-make-scml-animation](../../dst-make-scml-animation/GUIDE.md)` 检查 pivot、层级、镜像和逐帧替换。

## 阴影、FX 与 UI

阴影：使用独立、压扁、不规则的深色形状，边缘可有明显半透明和手绘破碎感。阴影必须接地，不复制主体轮廓后高斯模糊。

### 阴影组织（多物体打包）

为一组自定义建筑、生物或物件统一做落地阴影时，可按阴影贴图集（shadow atlas）组织；这只解决“怎么摆”，单块形状仍须遵守上一段的 DST 手绘阴影规则。

- **分区打包**：硬边区放矩形碰撞体、轮廓方正的物体（箱、墙、家具），用矩形块省精度；软边区放角色、树、怪物等复杂轮廓，单独留羽化空间。两类不混排，矩形尽量靠边对齐，便于按 UV 切片。
- **留 padding**：块与块之间至少留 2–4px，避免双线性采样渗到相邻阴影。
- **一块一语义**：每块只对应一个或一类物体的投影，不烘死整场景光影；运行时按实体位置和 anchor 取对应 UV 单独画。
- **配套 uv 表**：用 json 或 tilemap 记录每块的名称与矩形范围，打包与取用都不靠目测。
- **风格边界**：分区与 padding 借鉴引擎 atlas 结构即可；羽化边缘的笔触必须按 DST 手绘规范重画，不要直接沿用干净的引擎生成阴影。

FX：允许软边、透明渐层、纯亮色和复用小图。先保持生命周期与方向清楚，再决定是否加墨线。水滴样本比实体物更亮、更软，半透明比例也更高。

UI：匹配目标 UI 族的画布、边距和可点击区域。可比世界物体更正面、更简化，但仍保留不均匀线重和图形化明暗。文字、数字和状态图标必须优先保证可读性。

发光：把发光主体、光晕和粒子拆层。主体仍有核心形状，光晕承担透明扩散，避免整张图一起模糊。

## ImageGen 提示结构

生成位图时按以下顺序写提示，并附上同类参考图：

1. 资产身份与游戏功能。
2. 观察角度、朝向、比例和必须可见的部件。
3. 主轮廓和夸张焦点。
4. 近黑手绘线、粗细变化、断线与材质排线。
5. 主色、暗面、亮面、焦点色和材质词汇。
6. 透明 RGBA 背景、目标像素尺寸和 padding。
7. 动画拆件时说明每个部件独立、完整、不重叠或按指定方式重叠。
8. 排除项：无文字、无边框、无场景背景、无照片质感、无光滑 3D、无均匀矢量线、无白色抠图边。

生成后不要直接接受：在实际尺寸重画脸、握点、关节、轮廓断点和透明边；删除无法解释的细节；用参考资产校正线重和视角。

## 验收清单

- 1x 尺寸可立即识别主体、方向和功能。
- 剪影具有明确大中小节奏，非完美对称但结构可信。
- 外轮廓、内部结构线和材质线有线重层级。
- 黑色参与塑形，不只形成均匀边框。
- 明暗色块清楚，焦点色集中，材质不靠通用噪声。
- 与同资产族的视角、比例、光源和细节密度一致。
- 透明边在浅深背景无白晕、黑框、残底或断线。
- 动画部件接缝、遮挡余量和 pivot 区域完整。
- 镜像后不对称符号、文字性结构、握持方向仍正确。
- PNG 尺寸和 SCML 声明一致；占位 symbol 按契约保留。
- 成果没有逐像素复制原资源，仍表达新资产自己的设计。
