## 从参考提炼画法

| 维度 | 观察与提示方式 | 避免 |
|---|---|---|
| 线 | 以目标显示尺寸判断内外线相对粗细、颜色、转折和收笔；细线也能完整有力 | 所有图固定粗黑边，或“手绘”就加乱线 |
| 明暗 | 判断硬边色块、局部柔和过渡、窄刃高光各出现在哪 | 强制每体块 2–4 阶、禁止一切渐变 |
| 材质 | 金属看窄亮边与暗缝；木看顺势纹理；玉/珠看高光和通透；布看折面与边缘 | 每种材质都加裂纹、鳞片、划痕 |
| 色 | 主色、暗部和焦点的相对面积、冷暖及纯度 | 所有物体压成灰棕，或整件霓虹 |
| 细节 | 重点处结构完整，过渡处简洁，留净的大面衬托装饰 | 精致等于全图中高密度；所有微纹都要在 64 逐条可见 |
| 完成度 | 接合合理、边缘干净、线面有主次；和选定参考并排判断 | “高细节矢量插画”替代实际观察 |

手绘感可以表现为流畅而有轻重的轮廓、概括过的明暗和有节奏的形体。局部亮珠和柔和明暗并不自动变成 3D；看整件是否保持参考的线面组织，别机械禁用某种效果。

## 形制规范

画法与结构分别验收。先写器物类型、部件、连接关系、相对比例、装饰位置与用户保留项，再写画风。描述中国器物时可使用剑脊、剑格、剑首等准确名称并解释形状；词语本身不能保证形制，实际比例与连接描述更重要。

```text
类型与职责：
保留的结构 / 新设计方向：
部件及连接：
比例和视角：
纹样的位置、走向与表面厚度：
用户明确排除：
```

例如用户选择中式双刃直剑时，先说明直身双刃、剑脊、剑格、握柄和剑首的关系；是否带穗、玉具、盘形首以及长宽比例按用户选定形制确定。不要把一个示例的刃柄比写成所有古风剑的历史通制。专门历史或神话器物不确定时先查可靠来源，再给方案。

纹样需说明是刻纹、齐平镶嵌、浅浮雕还是独立构件；环绕需说明正侧背的遮挡。用户只要龙元素时，不自动增加活龙、夸张龙头或异文化配饰。

## 生成与后处理

按 [提示模板](reference-led-prompts.md#提示模板) 填写本轮必要内容，实际传入选定参考；不再使用固定“vector-illustration hybrid + 中高细节 + 禁渐变”的通用长提示。

优先生成 RGBA 真透明；只有工具确实不支持透明时才考虑纯色底，并避开主体已有颜色。黑底显示不代表文件没有 alpha。

在本专题目录运行：

```powershell
python tools/process_texture.py <generated.png> --name my_item --out <独立输出目录> --review
```

默认不抠底、不擦角，保留 master；256/64 统一缩放，REVIEW 展示原尺寸及放大辅助。旧命令的 `--no-key --no-watermark` 仍兼容。纯色底确需抠除时显式传 `--key-background` 并检查主体同色区域；`--clear-watermark` 是旧的右下角亮色擦除启发式，可能误伤主体，不作为常规流程。

面积占比是 alpha 边界框面积，不是可见像素数或高度；细长资产受长边限制，按同职责图选择留白。256 画布不会自动决定世界大小，参见 [显示尺寸](../assets/vanilla/DISPLAY_SIZE.md)。

## 验收

- 结构与用户认可方向一致；不把风格参考的饰件顺带复制。
- 与主参考并排看线重、明暗边界、材质和疏密；不是只看“像成品”。
- 256 看结构和线面质量，64 看主体、主色与焦点；人物和世界资产另查实际尺度。
- 浅深底透明边完整；缩放后半透明线条没有异常变淡。
- 用户确认前保留候选状态；不把自己的判断写成用户已认可。
