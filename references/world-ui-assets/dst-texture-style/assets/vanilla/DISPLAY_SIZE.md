# 展示实际大小（怎么调）

## 三种大小
1. **UI 图标感知大小**：64 格子里内容占比。调的是留白/裁切，不是进游戏 scale。
2. **世界展示大小**：`world/swap` symbol 的像素尺寸（默认 zoom 约 1:1）。过大过小主要改这里。
3. **母版画布**（256/512）：只是画的时候清晰；导出进 build 时会按 symbol 裁切/UV。

## 调整方法
| 现象 | 调整 |
|------|------|
| 背包里图标显得大/小 | 改 icon **面积占比**（`process_texture.py --icon-ratio`，工具约 0.50–0.70，偏满装备 0.85–0.95） |
| 地上实体过大/过小 | 改 build 中 symbol 的像素尺寸后重编译；或 `AnimState:SetScale` / prefab scale |
| 手持武器比例怪 | 改 `swap_*` 尺寸并校 pivot |
| 只有概念图 | 先出 256 母版 → 按目标 symbol 尺寸导出；勿把 256 直接当展示大小 |

## 原版对照（默认 zoom）
- 角色高度约 200px 量级
- 工具/武器 world 常见约 100–200px
- 小掉落物约 80–150px
- 建筑件可达 200–300px+
- FX 不受实体尺寸约束
