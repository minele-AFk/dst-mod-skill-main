# 古风 Mod 贴图·共用画风语法（可迁移）

仅在选定本批对应样本为主参考时使用；表中画法是本批的候选特征，不是所有 Mod 的硬规则。新参考优先于本表，按 [参考驱动流程](../../references/reference-led-prompts.md) 取用。
**只提炼画法，禁止复述单图题材**（“这张有荷叶/椒”不进规则）。

## 六项语法

| 维度 | 规则 | 禁止 |
|------|------|------|
| 线 | 近黑闭合描边；外轮廓粗于内结构；镂空/羽丝内线更细 | 毛边、发丝网、未闭合 |
| 体块 | 每主体 2–3 阶**硬边分面**（亮/主/暗） | 纯平涂；喷枪/3D 塑料渐变 |
| 材质 | 见各组特有表；通用：材质痕迹服务形体与受力 | 全图噪声纹理 |
| 色 | 大面低饱和（灰青/陶褐/草黄/金铜/粉米）；焦点少而准 | 整件同彩度；霓虹糊满 |
| 视角尺寸 | 多为 3/4 俯视静物/道具；接地或悬浮统一；64px 剪影可认功能 | 正俯视扁平；透视乱 |
| 完成度 | 终稿：边缘闭合、缺口/纹样有意、密度中高可读 | 草图感；噪点充细节 |

## 材质特有

| 材质 | 画法 |
|------|------|
| 石/陶 | 不规则分面+深缝；釉面高光只给一点 |
| 茅草/编织 | 短笔层叠+层间暗缝；单元可重复 |
| 金属/金器 | 棱面+刃口亮边+短划痕 |
| 晶体 | 硬棱+一点高光+贴体柔光 |
| 织物/绳 | 软分面+结绳单元 |
| 羽旄 | 长线成束，外轮廓完整 |
| 纹样（篆/云/火印） | 小面积开光，不铺满 |
| 水面/能量 | 平涂+1–2 条高光；忌照片涟漪 |

## 职责剪影

| 组 | 剪影要点 |
|----|----------|
| building | 体量接地；轮廓可认类型（屋/钵/炉/盆） |
| food | 静物可吃/可盛；64 能认是食材或容器 |
| equip | 竖长条（剑杖）或紧凑团（囊）；功能=砍/施法/佩戴/收纳 |
| item | 图标态强剪影；与同题装备色板一致 |

## 生成用法

提示只取选定样本支持的画法，实际传入主参考并说明职责；用当前可用的图像编辑工具有界修改，`process_texture.py` 保留透明度并输出尺寸预览。
验收 = 与主参考并排匹配线面和材质 + 结构正确 + 实际尺寸可读；三者缺一不可。

## 形制优先

画风语法不包含器物结构。组装提示时先写**形制部件与连接比例**，再写线/面/色，见 [形制规范](../../references/mod-clean-style.md#形制规范)。

## 入库核对纪律

- 一批图单独看完再命名，**禁止套用上一批的印象**（刀/剑、紫/青、纸/花易混）。
- 色名与器类以用户核对为准；不确定就出编号对照板再定。
