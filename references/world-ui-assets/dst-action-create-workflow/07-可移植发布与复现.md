# 07 可移植发布与复现

本页定义跨电脑复现和发布边界，不替代 04 的编译与验收步骤。

## 1. 路径与环境变量

项目和文档使用相对路径，不提交个人盘符、用户名或 Steam 库位置。外部工具通过环境变量或项目本地配置提供：

| 配置项 | 指向内容 |
|---|---|
| `DST_GAME_HOME` | 《饥荒联机版》安装根目录 |
| `OPENSPINE_HOME` | OpenSpine 安装或构建目录 |
| `DST_MOD_TOOLS_HOME` | 官方 Don't Starve Mod Tools 目录 |
| `DST_SCML_ANALYZER` | 已审核的 SCML 分析器；不使用时不设置 |

发布包排除 `.git/`、`local_config.json`、`__pycache__/`、缓存目录、临时导出、个人截图、浏览器 profile 和日志中的秘密。`build/` 可留在本地；只有清单明确需要时才发布筛选后的可复现中间报告。

## 2. 开工冻结项

先记录以下契约，再开始批量制作：

- bank、build、entity、动作名、方向。
- 固定 30 FPS、每段时长/帧数、命中事件、循环方式和末姿保持。
- 角色基础 Build、皮肤、装备和运行时替换关系。
- 交付格式、环境变量、输出目录和允许覆盖的范围。
- OpenSpine 编辑/采样/导出/校验构建版本与脚本版本。

动作名、事件或 build 归属不明确时写“待确认”，不能从其他资源猜。

## 3. 可复现链

```text
源参考与批准设计
  -> OpenSpine 母版（30 FPS）
  -> 原生采样与预览（30 FPS）
  -> SCML + 全部引用 PNG（绝对帧号换算毫秒）
  -> 官方 Mod Tools 编译
  -> 最终 anim.bin / build.bin / TEX
  -> 游戏内与联机验证
```

每一步保存：

- 输入和输出的相对路径。
- SHA-256 与修订号。
- 工具名称、版本/构建指纹和依赖。
- 完整命令、工作目录、退出码和日志。
- 实际产物检查结果，不只记录“命令成功”。

## 4. 编译与最终核验

1. 用 P0 小样验证当前官方编译链确实产出 30 FPS。
2. 从最终 `anim.bin` 逐动作读取实际 FPS、帧数、时长和事件。
3. 核对 bank/build、动作、方向、symbol 与纹理依赖。
4. 用游戏实际 Build/TEX 重建替换画面，检查原点、轮廓、UV、透明边缘和装备/皮肤关系。
5. 某些已测编译器固定输出 40 FPS 时，使用经过验证的适配链保留姿势、时长、事件和循环边界；不能改最终要求、改预览速度或篡改二进制 FPS 字段。

无法完成官方 30 FPS 编译与核验时，明确标记“30 FPS 编译未通过，阶段交付”，P0/G6 不得放行。

## 5. 发布清单

- [ ] SCML、全部引用 PNG、OpenSpine 母版和说明使用相对路径。
- [ ] 30 FPS 全链路配置、SCML 量化规则和最终二进制实测记录齐全。
- [ ] 编译适配脚本及 P0 保真证据可随项目复现，历史记录未冒充新验收。
- [ ] 最终 `anim/*.zip`、依赖 Build/TEX、CRC、SHA-256 和安装映射完整。
- [ ] 预览媒体与源/编译包同版本，未把工程 ZIP 命名为游戏动画包。
- [ ] 游戏内、主机、远端客户端、重连和重载结果分别记录。
- [ ] 未执行项、已知问题、工具版本和阻塞原因明确。

## 6. 可移植性验证

- 在另一台电脑或干净目录解压后，不修改脚本即可找到相对资源。
- 只通过环境变量配置工具路径，不依赖原制作者的用户名或盘符。
- 缺少可选工具时给出明确错误，不静默使用旧产物。
- 重新运行构建得到的哈希与清单一致，或差异有可解释记录。
