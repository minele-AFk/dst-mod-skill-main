# 00 注意事项

本页集中放置跨阶段硬性规则，详细步骤仍按 01-07 执行。

## 30 FPS 时基

- OpenSpine 母版、关键帧时间基准、原生采样、预览播放和最终编译动画统一以 **30 FPS** 为目标。不得因工具默认值改交 24、25、40 或 60 FPS；帧率要求进入 P0 与 G6 验收。
- “30 帧”指每秒 30 帧，不是每个动作总共 30 张。每段分别记录循环周期/单次时长、采样帧数、末姿时间和保持段。
- F0 为零时刻，`t = F / 30` 秒；F12 = 400 ms，F15 = 500 ms，F30 = 1000 ms。
- SCML 整数毫秒从绝对帧号换算：`round(F × 1000 / 30)`。F0/F1/F2/F3 = 0/33/67/100 ms；间隔 33 或 34 ms 是有意量化，不能累计固定 33 ms。
- 最终从 `anim.bin` 逐动作读取实际 FPS、帧数和时长，并核对命中/换图等事件。只改预览速度、文件标签或二进制 FPS 字段不满足要求。
- 某些已测官方编译器固定输出 40 FPS；这描述已测版本，不推断所有版本。P0 必须实测当前工具链，并记录工具版本/哈希、输入时间网格、完整命令和产物实测值。
- 若工具输出 40 FPS，不能把最终要求改成 40 FPS；通过经过验证的适配链保留姿势、时长、事件和循环边界，否则标记“30 FPS 编译未通过，阶段交付”。

## 资源与运行时归属

- 动画包内的 Build 不等于游戏实际使用的 Build。制作前确认角色基础 Build、皮肤、装备和临时覆盖的实际来源；G7 必须组合安装包的 `anim.bin` 与运行时真正选中的 `build.bin`/TEX 验证。
- 预览、GIF/MP4、PNG 帧序列和 OpenSpine JSON 不能替代 SCML 源工程与官方编译 `anim/*.zip`。
- 源工程、PNG、编译包和验收媒体必须对应同一修订版；修改源后重导出、重编译和重校验。

## 证据边界

- 文件存在、自动化检查通过、用户实际能打开、游戏内加载、主机与远端客户端一致分别记录。
- 未执行游戏、专服、客户端 UI、动画编译或联机验证时，必须写明“未执行”，不能写成已通过。
- 历史案例中的旧时基、旧工具和旧构建结果照实保留，不反向改写为新规范已通过。
