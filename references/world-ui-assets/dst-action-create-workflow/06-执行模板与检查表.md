## 4. 阶段检查表

### 设计与拆件方案

- [ ] 已读当前仓库或团队的 DST 规则及本阶段相关工具说明。
- [ ] 每个个体独立，风格候选与个体名称不混淆。
- [ ] 三视图版本和用户确认有记录。
- [ ] 先完成部件计划，再生成对应部件。
- [ ] 部件含必要隐藏接头，无重复牙齿、整腿、整头等多余内容。
- [ ] 图像工具原图、提示词、实际模型和版本记录可追溯。
- [ ] 显隐与层级有记录，不把隐藏部件强行叠到前景。

### P0 技术小样，必须在批量制作前执行

- [ ] 单个体循环和单次短动作覆盖代表性方向、IK/Transform、层级及实际需要的换图/显隐。
- [ ] 原生与 SCML 独立重建画面对照通过，功能边界和时间量化误差已记录。
- [ ] 官方工具真实编译样包，命令、工作目录、依赖/脚本版本、日志、退出码和哈希齐全。
- [ ] 已在明确授权的隔离模组和测试世界加载，不覆盖正式资源或修改用户存档。
- [ ] 已用同源在新空输出目录重建并核对语义产物，未误用缓存旧包。
- [ ] 未完成小样或仅获中间阶段授权时明确记录风险和范围，不将其写成通过或默认放行批量制作。

### 全部拆件、拼合与骨骼

- [ ] 全部独立 PNG 可打开，无漏件、空图、残底和断边。
- [ ] 拼合预览由实际交付 PNG 生成。
- [ ] 与批准三视图同尺度对照，比例、颜色和关节修正有前后证据。
- [ ] 未把静态连通或临时关节点描述为已通过动画验收。
- [ ] 骨架、父子继承、约束和关键帧真实存在且可编辑。
- [ ] 每个个体身份独立；双头等特殊结构有独立骨链。
- [ ] `side` 原生朝右，左向完整镜像，所有动作均已复查。
- [ ] 张嘴、抬腿、蹲低、尾摆和死亡等极限姿势检查完成。
- [ ] 工程保存重开后骨骼矩阵与附件没有意外变化。
- [ ] 正背面逐腿核对解剖左右与实际弯曲，没有照抄屏幕左右或 IK 极性符号。
- [ ] Transform 的受控骨、来源骨、`properties` 及各动作 mix 已核对，并在工作副本用 0/1 诊断姿势证明实际生效。
- [ ] 抬脚、支撑、缩放继承和远侧腿显隐已逐帧检查，脚掌未被小腿带翻或压扁。
- [ ] IK 极性切换、IK/FK 与脚掌约束切换的相邻帧无跳姿，实际误差与容差有记录。

### 动作与交付

- [ ] 待机稳定，行走支撑合理，IK 目标可达。
- [ ] 攻击姿势与代码命中帧对照，不以预览事件自动替代伤害逻辑。
- [ ] 死亡重心和接地可信，末姿保持，缺少表情附件时已明确报告。
- [ ] 本项目规定的死亡姿势逐方向核对；三狼正背面是双前腿跪地、头胸下沉，不是旋转侧倒画面。
- [ ] 循环首尾连续且没有重复导出端点造成停顿。
- [ ] 每段原生输出无空白、裁边、明显脱节，透明通道有效。
- [ ] 四方向同步预览、逐帧、拖动和死亡重播可用。
- [ ] 验收入口指向当前修订；提供无页内参数的 HTML 文件路径及独立动画/图片。
- [ ] 用户无法打开时记录具体症状；工具返回排队或安全拦截不写成已成功打开。
- [ ] 桌面/手机预览已检查，测试进程已关闭，未操作用户原有窗口。
- [ ] 工程、PNG、说明、证据、脚本和包内外文件清单齐全。
- [ ] 工程归档 ZIP 与校验记录一致；不将它当作游戏动画包。用户验收结果单独记录。

### 局部返工回归

- [ ] 基准工程、PNG、采样数据和工具版本已冻结，手改母版已保留。
- [ ] 允许修改的个体/方向/动作/骨骼/属性/时间段已列明；共享 setup 或素材变化已扩大影响范围。
- [ ] 首末姿势、事件、时长、脚踝目标等不变量与未修改的语义轨道、PNG 哈希已核对。
- [ ] 基准与修订使用同构建采样；矩阵、顶点和原生画面对照有预先规定的容差与最大误差记录。
- [ ] 目标问题通过专项复测，其他个体、方向和动作完成回归；没有未解释的范围外变化。
- [ ] 无基准或未重跑时标记未验证，不声称其他动作完全不变。

### 最终源工程与游戏动画包，必须交付

- [ ] 补齐所有代码需要的动作；三狼当前案例尚缺 `hit`，新项目按自身契约填写缺项。
- [ ] bank/build/entity、方向、symbol 和个体外观选择已核对。
- [ ] 已交付同版本 `.scml` 与全部引用 PNG，相对目录完整，保留 OpenSpine 骨骼母版。
- [ ] SCML 引用、PNG 尺寸、时间网格和事件对齐检查通过。
- [ ] 对剪切、晚出现附件、换图、透明度和网格等功能逐项标明支持/不使用/待实现，没有静默丢效果。
- [ ] 以独立 SCML 重建画面对照原生输出，首末、命中、换图/层级切换等关键时刻及全段数值检查通过。
- [ ] 官方 Mod Tools 已实际运行，保存工具版本、命令、工作目录、退出码和构建日志。
- [ ] 已交付本轮实际编译的 `anim/*.zip`，不是工程归档或仅含 XML/PNG 的中间包。
- [ ] 检查 `anim.bin`、`build.bin`、TEX 纹理及分包依赖完整，并核对包内命名、动作与方向。
- [ ] 编译后画面对照状态单列；没有包渲染或游戏结果时明确写待验证，未拿原生视频冒充。
- [ ] 编译包 CRC 与 SHA-256 有记录，源文件哈希、媒体、说明和产物对应同一修订。
- [ ] 最终清单写明源文件路径、游戏包路径、目标安装路径与 Asset/bank/build 对应关系。
- [ ] 修改源后已重新导出、编译、验包；没有拿旧包冒充本轮编译结果。
- [ ] 编译未完成时标记“阶段预览/源工程，最终交付未完成”，不宣告整套动作完成。

### 游戏接入与实测，未执行不得打勾

- [ ] G6 源文件与编译包交付已完成；G7 游戏验收状态单独记录。
- [ ] 经明确接入范围确认后更新资源和代码。
- [ ] 游戏实际尺寸、转向、状态衔接、伤害和死亡实测完成。
- [ ] 客户端、服务端、联机与日志检查完成。

- [ ] 启停与行走周期、步幅/移速、攻击恢复/打断、不同前置状态死亡均有游戏记录。
- [ ] 主机本地与远端客户端分别观察，重载后复查；游戏成品与同版导出画面对照通过。
