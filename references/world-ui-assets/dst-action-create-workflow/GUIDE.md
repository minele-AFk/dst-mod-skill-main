# DST 动作制作流程（dst-action-create-workflow）

把角色参考转成可编辑、可验收、可编译交付的 DST 骨骼动画的完整工作流。来源于实际三狼 C 风格制作案例的复盘沉淀。

**核心纪律**：最终交付必须同时有 SCML 源工程及全部引用 PNG，以及用官方 Mod Tools 实际编译完成的 `anim/*.zip`。预览（网页/GIF/PNG帧序列/OpenSpine JSON）不构成交付完成；除用户明确只要求中间阶段外，不得以"预览已做好"当作完成。
