# API 更新影响评估

## 风险分级

| 级别 | 定义 | 示例 |
|---|---|---|
| 必然破坏 | 原有代码无法运行 | 移除函数、改变签名 |
| 高风险 | 行为严重异常 | 返回值变化、新增必填参数 |
| 行为变化 | 功能可用但结果不同 | 参数默认值变化 |
| 低风险 | 无功能影响 | 内部实现变化 |
| 未影响 | 无变化 | 新增函数、新增选项 |

## 检查清单

- [ ] modutil.lua 中的公开 API 是否变化？
- [ ] 使用的 Component 方法是否被移除？
- [ ] netvar 类型或名称是否变化？
- [ ] SG 状态名是否重命名？
- [ ] 存档数据结构是否变化？
- [ ] 网络协议是否变化？

## 迁移策略

1. 备份当前 mod 版本
2. 运行快照比较工具
3. 按风险分级处理
4. 回归测试关键功能
5. 提交新版本并标记兼容性
